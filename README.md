# 왕전초 점프왕 (Wangjeon Jump King)

발판을 밟고 **바닥 레이저**를 뛰어넘어 깃발까지 달리는 가로 스크롤 점프맵 게임입니다.
`♡왕전초 연산왕!♡` · `♡왕전초 타이머왕!♡` · `♡왕전초 눈치왕!♡`와 같은 왕전초 시리즈예요.

**바로 플레이:** https://chohanui2-home.github.io/wangjeon-jump/

## 게임 규칙

- ◀ ▶ 로 달리고, **점프 ⬆** 로 뛰어요.
- **점프를 한 번 더 누르면 🌀 회오리 점프!** 사람 캐릭터가 360° 빙글빙글 돌면서 소용돌이 바람이 일고, 일반 점프보다 더 높이·더 멀리 날아가요.
- 바닥에 반짝이는 **빨간 레이저**를 밟으면 찌릿! 실수가 하나 올라가고, 가장 최근에 밟은 **🚩 체크포인트**(없으면 단계 시작점)로 되돌아가요. 죽지는 않아요.
- **🌀 회오리벽**은 그냥 점프로는 막혀요(튕겨 나올 뿐 다치지 않음). 회오리 점프로 돌면서 부딪히면 팡! 하고 부서지며 돌파!
- ⭐ 별 코인을 모으고, 🏁 깃발에 닿으면 클리어!

## 6단계

| 단계 | 이름 | 내용 |
|---|---|---|
| 1 | 첫 걸음 | 넓은 발판 + 짧은 바닥 레이저 + 회오리벽 |
| 2 | 계단 발판 | 오르내리는 계단 발판 |
| 3 | 움직이는 발판 | 좌우로 오가는 발판을 타고 건너기 |
| 4 | 통통 스프링 | 스프링을 밟아 하늘 높이 날아오르기 |
| 5 | 깜빡 레이저 | 꺼졌다 켜지는 레이저 + 좁은 발판 |
| 6 | 점프왕 코스 | 체크포인트 2개 · 움직이는 발판 · 스프링 · 레이저 총집합 |

화면 맨 아래 탭에서 언제든 단계를 바꿀 수 있고, 클리어한 단계에는 ★(별 1~2개) · ♛(별 3개) 표시가 붙어요.

## 특징

- **초등학생 손에 맞춘 조작** — 멀티터치 포인터 이벤트로 이동하면서 동시에 점프, 2단 점프(회오리), 코요테 타임(발판 끝을 살짝 지나쳐도 점프), 점프 버퍼링(누르고 있으면 착지하자마자 점프)까지 넣었어요. 키보드 방향키·WASD·스페이스도 돼요.
- **6단계 모두 실제로 깨지는지 검증** — 게임과 똑같은 물리 엔진을 오토파일럿이 직접 달려서 1~6단계를 모두 완주하는지 자동 테스트로 확인합니다.
- **사람 캐릭터** — 둥근 얼굴에 웃는 입, 라벤더 티셔츠·파란 반바지·민트 운동화를 신은 아이 캐릭터가 달리기·점프·회전·감전 표정을 지어요.
- **라벤더·민트·레몬 하늘 테마** — 연산왕/타이머왕(파랑), 눈치왕(코랄)과 겹치지 않는 산뜻한 파스텔 아케이드.
- **기록 저장** — 단계별 최고 기록(시간·실수·별)을 브라우저에 저장하고, 새 기록이면 '새 기록!' 표시.
- **효과음** — 점프·회오리·코인·체크포인트·감전·회오리벽 파괴·클리어 팡파레 (Web Audio API, 음소거 가능).
- **외부 리소스 0건** — 폰트·CDN·이미지·오디오를 하나도 불러오지 않는 단일 HTML 파일. 파일 하나만 보내도 오프라인에서 그대로 열립니다.
- **앱처럼 설치** — 홈 화면에 추가하면 전체화면 앱처럼 열립니다(PWA 메타·아이콘·매니페스트 포함).

## 파일

- `index.html` — 게임 전체가 들어 있는 단일 파일(외부 요청 0건)
- `app_template.html` — 빌드용 템플릿(아이콘 자리표시자 포함)
- `build.py` — 아이콘 주입·단일 파일 규칙 검사 후 `index.html`과 `dashboards/왕전초-점프왕.html`에 같은 바이트로 기록
- `test_app.py` — QuickJS로 게임 스크립트를 실행해 물리·충돌·레이저 리스폰·체크포인트·회오리벽·1~6단계 도달 가능성을 검사하는 자동 테스트

## 다시 빌드하기

```bash
python3 build.py      # index.html + dashboards/왕전초-점프왕.html 생성
python3 test_app.py   # 자동 테스트(118건)
```
